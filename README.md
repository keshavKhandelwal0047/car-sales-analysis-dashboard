# 🚗 Car Sales Analysis Dashboard | Microsoft Excel

## 📌 Project Overview
An interactive Excel dashboard built using a dataset containing 1,200+ car records to analyze sales performance, vehicle specifications, pricing, and resale value.

## 🛠️ Tools & Skills
- **Microsoft Excel:** Formulas, PivotTables, charts, and interactive filters
- **Data Analysis:** Data exploration, performance comparisons, and KPI analysis
- **Data Visualization:** Interactive dashboards and chart-based reporting

## 📊 Key Areas of Analysis

- **Sales Analysis:** Unit sales, selling prices, and resale values
- **Vehicle Analysis:** Models, manufacturers, engine size, horsepower, and fuel efficiency
- **Performance Analysis:** Resale value retention and power performance factor
- **Vehicle Specifications:** Vehicle type, dimensions, curb weight, and fuel capacity

## 📈 Dashboard Features

- Model-wise unit sales analysis
- Average selling price versus resale value
- Power performance comparisons across models
- Manufacturer- and model-level filtering
- Key performance indicators for quick insights

## 📁 Workbook Structure

- `Car_sales` — Source data containing vehicle and sales information
- `Bar Chart` — Bar chart analysis
- `Column, Pie, Sunburst Chart` — Additional visualizations
- `Dashboard` — Interactive dashboard bringing key metrics and charts together

## 🚀 How to Explore
1. Download `Car_Sales_Analysis_Portfolio.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Explore the analysis sheets and use the interactive filters on the dashboard.
